# Galaxy Gallery

Experiencia web romantica e interativa com Three.js.

## Como usar

1. Abra `index.html` no navegador
2. Coloque suas fotos em `assets/photo1.svg` ~ `photo6.svg` (ou .jpg/.png)
3. Coloque sua musica em `assets/music.mp3`
4. Edite os poemas no array `POEMS` dentro de `script.js`

## Estrutura

```
galaxy-gallery/
  index.html
  style.css
  script.js
  assets/
    photo1.svg ~ photo6.svg  (substituir por suas fotos)
    music.mp3                 (substituir por sua musica)
```
